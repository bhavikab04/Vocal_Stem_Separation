Hear what’s inside a song.

One mixed track goes in. Isolated vocals and a backing track come out. Pick a demo, then solo each part, loop a section and compare it with the original.

Space plays and pauses, the arrow keys skip 5 seconds, and clicking a waveform seeks. These demos were separated in advance.

How it was built

Data

80 multi-stem songs from MoisesDB. Stems are grouped into vocals, drums, bass and other, and mixed on the fly into 7.8 second stereo crops, half of them remixes of stems from different songs.

Model

A pretrained HTDemucs fine-tuned with a vocal-weighted waveform loss. It followed two from-scratch models, a ViT-style spectrogram network and a hybrid spectrogram and waveform TasNet, which could not learn enough from 80 songs.

Result

Measured on 10 held-out songs. Fine-tuning moved a strong pretrained model by only a few hundredths of a dB, so the main finding is that small datasets add little on top of large-scale pretraining.

Run it on your own songs

The full app, with uploads, runs on your computer. You need Python 3.10 or newer and ffmpeg.

git clone https://github.com/bhavikab04/Vocal_Stem_Separation.git
cd YOUR-REPO
bash run.sh        # Windows: double-click run.bat
# then open http://localhost:8000
